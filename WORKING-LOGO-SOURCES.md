## Parent-brand rule

Do not create fake standalone logos for products that do not publish one.

Use:

- ChatGPT → current OpenAI/ChatGPT-approved mark as permitted by OpenAI brand guidance.
- Claude Code → Claude/Anthropic mark + `Claude Code` text label unless Anthropic publishes a dedicated current product mark.
- Claude Design → Claude/Anthropic mark + `Claude Design` text label unless Anthropic publishes a dedicated current product mark.
- Nano Banana Pro → Gemini/Google mark + `Nano Banana Pro` text label unless Google publishes a dedicated approved mark.
- Seedream → ByteDance/Seed product-family mark + `Seedream` text label unless a dedicated approved mark is published.

https://openai.com/brand/

### Anthropic / Claude / Claude Code

Use Anthropic's current newsroom / press-kit / official product materials.

Do not fabricate dedicated Claude Code or Claude Design logos.

### xAI / Grok

### Seedream / ByteDance

## Completion gate for Claude Design

Before the AI portfolio branch is considered design-complete:

1. Every tool actually displayed on the website must have a corresponding asset in the Drive `Tool Logos` folder.
2. Every displayed asset must be checked against the vendor's current official product/brand material.
3. Canva, Magnific, and Topaz must be retrieved from their official sources rather than being omitted.
4. If a tool does not publish a standalone product logo, use an approved parent/company/product-family mark plus a text label.
5. Final public website copies must be committed to `assets/ai-portfolio/tool-logos/` in `ng549/ndgcv`.
6. No website logo treatment may imply partnership, endorsement, employment, or sponsorship by the vendor.
