# Strongest Portfolio Proof Points

## 1. Burnt Toast XDJ Virtual Mixer / ATOMIK origin

This is one of the strongest technical artifacts because it crossed beyond visual design into functioning real-time browser software. Evidence in the Claude Design package includes a four-deck architecture, mixer, beat FX, sampler/step sequencer, file-library ingestion, BPM/onset analysis, Web MIDI control, IndexedDB persistence, and File System Access integration.

Professional framing:

> Conceived and directed a browser-based real-time DJ/performance platform combining audio processing, hardware control, local media management, persistence, analysis intelligence, and a performance-oriented interface; later evolved the platform into ATOMIK.

## 2. PARKOUR Control Tower

PARKOUR is the clearest proof that the AI work is about systems and operating models rather than isolated prompts. Claude Design contains five connected product surfaces: Control Tower, Grand Central, Communications, AI Cost Intelligence, and Integrations.

The design includes agent registration, human approval queues, AI-to-AI messaging states, quarantine, containment, provider routing, cross-provider context, cost attribution, integration health, and emergency-stop behavior.

Professional framing:

> Designed a multi-agent AI operations platform that treats AI systems like a governed workforce, with agent identity, ownership, communication, cost control, human approvals, safety controls, observability, and durable GitHub coordination.

## 3. Video Production Pipeline

This is a particularly useful proof point because the integrations are not purely conceptual. The Claude package documents working Google Sheets/Drive integration plus an Apps Script server-side proxy for OpenAI image generation, keeping API credentials off the frontend.

Professional framing:

> Designed and implemented a multi-tool AI production workflow that converts creative work into a trackable stage-based operating system, with live Google infrastructure and server-side AI API integration.

## 4. FLOOR/DESK Broker Terminal

This shows the ability to convert domain judgment into software. The product treats ticket inventory as a trading book and centers the experience on dollars at risk, sell-through pace, days-to-event, floor pricing, undercutting, and recommended repricing actions.

Professional framing:

> Translated inventory, margin, markdown, and sell-through logic into a decision-intelligence product for perishable ticket inventory.

## 5. UNIT Point of Sale

UNIT ties the new technical capability directly back to retail operating experience. The multi-business selector, hold tabs, weighted items, device ergonomics, barcode/PLU logic, offline readiness, and system status signals show practical store-floor thinking.

Professional framing:

> Designed an operator-led multi-business POS concept around real store-floor requirements rather than generic software conventions.

## 6. EDU K8 DJ Pro

EDU K8 demonstrates range and reuse. It combines an emotionally accessible consumer experience with actual browser audio analysis and reuses technical learning from the larger music/performance program.

Professional framing:

> Extended real-time audio-analysis capabilities into a simplified consumer learning product, demonstrating reuse of technical foundations across distinct product experiences.

## 7. Foundry Agent Ecosystem

Foundry is important as an early expression of the agent thesis: decompose an entire business into specialized AI roles, keep the human in the approval loop, and make each role observable.

Professional framing:

> Designed an AI-operated e-commerce model in which specialist agents own research, design, content, listings, scheduling, and analysis while the human retains approval and strategic control.
