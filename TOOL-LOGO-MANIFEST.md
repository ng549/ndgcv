# Brand-Safety / Accuracy Rules

1. Do not imply that Nicolas works for, is certified by, or is partnered with any tool company merely because he uses the product.
2. Do not use company marks more prominently than Nicolas's own name/branding.
3. Do not recolor, distort, crop, animate, combine, or recreate marks unless the brand's current guidelines explicitly permit it.
4. If a product has no independent official logo, use its parent/product-family mark plus a plain text label rather than inventing a symbol.
5. When the CV site is implemented, re-check the current brand source before final production because AI product branding changes quickly.
