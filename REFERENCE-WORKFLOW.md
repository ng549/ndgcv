# Reference requests — approved scope

Nicolas personally approves requests. Email address: ngoureau@mac.com.

The private contact list must hold name, role/company, contact details, relationship to Nicolas, work shared, and what each person can speak to. Never include this private list in the public website bundle.

Requester supplies name, company/role, email, opportunity/story, and what they want to discuss. Nicolas reviews it, chooses references, and edits two previews before clicking Approve and send.

Send an individually crafted heads-up to each chosen reference, containing the requester's contact information, company, opportunity, and relevant questions. Send the requester an introduction email with only approved reference details and relationship context. No group blast, no automatic approval. Delivery must be tracked and retries must not duplicate messages.

Current preview implements an explicitly labeled email-draft request form addressed to ngoureau@mac.com. It does not store reference contacts, implement the private approval dashboard, or send automatically.

For automated sending from ngoureau@mac.com, securely connect iCloud SMTP (smtp.mail.me.com:587, STARTTLS, authenticated full email address, app-specific password). Never request or commit the primary Apple password. Set up provider credentials as server-side secrets after hosting/auth choices are confirmed. A verified sender domain with Reply-To ngoureau@mac.com is an alternative, not an equivalent sender identity.
