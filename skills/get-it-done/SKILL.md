# GET IT DONE

## Identity

Display name: **Get it done**  
Command: **Get it done**  
Scope: **Every project** that inherits PARKOUR standards.

This is not optional guidance. This is a standing law for every agent, every phase, every build.

## Core Law

**If the information, code, library, skill, pattern, test, or asset already exists out there — use it. Do not figure it out from scratch.**

Search first. Classify. Integrate or adapt. Only build the parts that truly do not exist or that must differentiate the product.

Full research matrix, classification rules, and mandatory sequence are defined in the PARKOUR skill of the same name. When this skill is triggered, follow that protocol rigorously.

When the user or another agent says **Get it done**, treat this entire skill as immediately active and binding.
