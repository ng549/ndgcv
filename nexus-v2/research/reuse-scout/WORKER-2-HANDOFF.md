# Nexus V2 — Worker 2 Phase One Handoff

Date: 2026-09-19  
Branch: `nexus-v2-p1-02-reuse-scout`

## Strongest recommendations

1. **Identity:** run a short WorkOS AuthKit vs Clerk implementation spike; do not build auth/org/invite primitives.
2. **Workflow:** Temporal Cloud for durable multi-step business workflows; simpler queues/jobs can use platform-native jobs where durability semantics are unnecessary.
3. **Integrations:** Nango first for customer-facing OAuth/API connectivity; direct official APIs where a connector is strategic/high-volume; Airbyte only for ELT/bulk replication.
4. **MCP:** prioritize official vendor remote servers. Put serious consideration into Cloudflare MCP Server Portals as the Nexus control point because it can centralize servers behind Access and policy.
5. **AI:** Nexus-owned gateway contract with LiteLLM-class provider abstraction; OpenRouter/other aggregators are provider routes, not the app contract; Langfuse for observability, not billing truth.
6. **Billing:** Stripe for money/invoices; OpenMeter for fine-grained usage/credits/entitlements if needed; reconcile with vendor invoices.
7. **Managed service:** OpenTelemetry plus managed Sentry/Better Stack-class services; do not build logs/uptime/on-call.
8. **Client UI:** custom Nexus shell and client UX; use proven React/form/table/chart libraries. Retool can accelerate bounded internal tools but should not become the transferable core product.
9. **Marketing:** Apollo/Clay + Smartlead-class outbound stack is faster than building discovery/enrichment/sequencing. Compliance and deliverability controls are mandatory.
10. **Support:** Chatwoot or commercial helpdesk; do not build ticketing.

## Proposed Architecture Change Requests

- **ACR-02-001:** Separate integration runtime (Nango/direct APIs) from durable workflow runtime (Temporal).
- **ACR-02-002:** Separate AI observability from the billable usage ledger.
- **ACR-02-003:** Establish MCP trust tiers and production admission review.
- **ACR-02-004:** Route approved external MCP through a governed MCP access layer where practical; evaluate Cloudflare MCP Server Portals as default.
- **ACR-02-005:** Make every third-party component record include version/commit + license/terms + replacement path.
- **ACR-02-006:** Do not allow low-code tools, helpdesks, CRMs or workflow engines to become the Nexus canonical source of project/task truth.
